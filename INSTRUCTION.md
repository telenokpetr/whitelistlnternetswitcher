# Инструкция: обход через роутер, панель, подписки

## 1. Как это устроено
```
устройство → роутер (RouteRich)
   ├─ РФ-сайты / локальная сеть ─────────→ напрямую
   └─ всё остальное → Xray (tproxy) → VK/Yandex CDN → сервер 194.39.110.184 → интернет
```
- **Роутер**: чистый Xray (`/etc/init.d/xray-vk`), перехват трафика LAN (`/etc/init.d/xray-tp`), конфиг собирается из подписки скриптом `/usr/bin/xray-sub-update.sh` (cron раз в 6 часов).
- **Сервер 194.39.110.184**: 3x-ui, nginx (443), бот и мини-приложение Telegram, зеркало списков (порт 8081), SOCKS-прокси для Telegram.
- **Выбор канала**: Xray сам берёт самый быстрый профиль (leastPing), если он упал, переключается на резервный.
- **Что идёт напрямую**: `geosite:category-ru`, домены .ru/.su/.рф, `geoip:ru`, локальные сети, торренты.
- **Не перехватываются**: DNS и NTP (UDP 53/123), адреса самих серверов. QUIC (UDP 443) блокируется, чтобы браузеры перешли на TCP.

## 2. Панель роутера
Адрес: **http://192.168.1.1:8088/admin/** (только из домашней сети).
Логин `admin`. Пароль хранится в `/etc/pc/httpd.conf` на роутере (строки `/admin:admin:ПАРОЛЬ` и `/cgi-bin/api:admin:ПАРОЛЬ`). Смена: поменять пароль в обеих строках и выполнить `/etc/init.d/pc-panel restart`.

Разделы:
- **Дашборд** (сворачивается): пинг до серверов подписки и устройств. Красный — нет ответа, жёлтый — больше 400 мс. Спящие телефоны могут не отвечать на пинг.
- **Обход блокировок**: общий переключатель. Выключение останавливает перехват и убирает автозапуск.
- **Устройства**:
  - переключатель «Обход» у каждого устройства отдельно;
  - родительский контроль: недельный лимит в часах;
  - название устройства меняется кликом по имени.
- **Создать подписку**: имя, лимит ГБ, срок в днях (0 = без лимита). Создаётся клиент в 3x-ui. Кнопки «Копировать» и «На роутер».
- **Подписка на роутере**: поле со ссылкой. Новая ссылка применяется сразу. Если не подошла, возвращается прежняя.

## 3. Родительский контроль (правила)
| Значение лимита | Что происходит |
|---|---|
| не задан | интернет на устройстве выключен |
| 0 (кнопка **Unlimited**) | без ограничений |
| больше 0 (часы в неделю) | время тратится, пока идёт трафик |

- Время считается только при реальном трафике (порог около 30 КБ за 10 секунд). Фоновая мелочь не считается.
- Лимит сбрасывается в понедельник в 00:00. Кнопки: «+15 мин / +30 мин / +1 час», «Сбросить», «Изменить лимит».
- Когда время вышло, интернет блокируется, но страница таймера открывается.
- **Страница таймера без пароля**: http://192.168.1.1:8088/ показывает остаток для устройства, с которого её открыли.
- Новые устройства блокируются, пока им не задан лимит (по умолчанию). Добавление нового устройства: подключить, открыть панель, нажать «Unlimited» или задать часы.
- Опознаётся устройство по MAC-адресу. Телефоны с «частным Wi-Fi адресом» (случайный MAC) для каждой сети выглядят как новые устройства. Для домашней сети лучше включить «использовать MAC устройства».

## 4. Если что-то сломалось
Все команды выполняются на роутере: `ssh -i ~/.ssh/router_rr root@192.168.1.1`.

| Проблема | Что делать |
|---|---|
| Интернет пропал у всех | `/etc/init.d/xray-tp stop` (перехват выключится, интернет пойдёт напрямую) |
| Включить обратно | `/etc/init.d/xray-tp start` |
| Xray не запущен | `/etc/init.d/xray-vk restart`, затем `logread \| grep xray` |
| Обновить подписку вручную | `/usr/bin/xray-sub-update.sh` |
| Панель не открывается | `/etc/init.d/pc-panel restart` |
| Устройство заблокировано по ошибке | в панели нажать «Unlimited» |
| Снять родительский контроль со всех | `nft delete table inet pc`, затем в `/etc/pc/config.json` поставить `"default_block": false` |
| Проверка канала | `curl -x socks5h://127.0.0.1:10808 https://api.ipify.org` должен показать IP сервера |

Автоматическая защита: каждую минуту `xray-tp-guard.sh` проверяет, слушает ли Xray порт 12345. Если нет, перехват снимается сам, чтобы не оставить сеть без интернета.

## 5. Что где лежит на роутере
| Файл | Назначение |
|---|---|
| `/etc/xray-vk.json` | конфиг Xray (генерируется, руками не править) |
| `/etc/xray-sub.url` | ссылка на подписку |
| `/usr/bin/xray-sub-update.sh` | сборка конфига из подписки, зеркало гео-списков |
| `/etc/init.d/xray-vk`, `/etc/init.d/xray-tp` | запуск Xray и перехвата |
| `/etc/xray-tp.devices` | `all` или список IP, для кого включён перехват |
| `/etc/xray-tp.off` | MAC-адреса, для которых обход выключен |
| `/etc/pc/config.json` | лимиты, имена, настройки родительского контроля |
| `/etc/pc/state.json` | сколько времени потрачено за неделю |
| `/etc/pc/httpd.conf` | пароль панели |
| `/etc/pc/server.key` | ключ для создания подписок на сервере |
| `/usr/bin/pc-daemon.sh` | учёт времени и блокировка |
| `/www-panel/` | сама панель |
| `/root/xray-tp.init.bak` | старая версия скрипта перехвата |

SOCKS5 для Telegram: каждый профиль доступен на `192.168.1.1:10811…` (порты и названия в `/etc/xray-vk.ports`), общий SOCKS на роутере: `127.0.0.1:10808`.

## 6. Сервер 194.39.110.184
Вход: `ssh -i ~/.ssh/id_ed25519_vpn root@194.39.110.184`.
- Бот: `systemctl status sub-bot`, файлы в `/opt/sub-bot/`, настройки `/etc/sub-bot.env`.
- Nginx: `/etc/nginx/conf.d/vk-origin.conf`, зеркало списков `/etc/nginx/conf.d/lists-ip.conf`.
- Копия бота перед последней правкой: `/opt/sub-bot/bot.py.bak-routerkey`.
- Роутер создаёт подписки через бота по ключу `ROUTER_KEY` (в `/etc/sub-bot.env` и в `/etc/pc/server.key` на роутере).

3. Продлить сертификат панели holhandia (истекает 21 октября).
4. Проверить создание подписки из панели (кнопка «Создать»).
