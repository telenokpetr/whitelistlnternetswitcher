# Пакет OpenWrt

Сборка на компьютере с Python 3:

```sh
python openwrt/build_ipk.py
```

Полученный пакет `dist/luci-app-ded-obhod_1.0.2-1_all.ipk` устанавливается через `opkg`. Для работы нужны настроенные репозитории пакетов OpenWrt и LAN с адресом роутера `192.168.1.1`, интерфейсом `br-lan`. После первой установки выполните на роутере `ded-obhod-setup`, чтобы задать пароль панели и запустить её. При обновлении существующие пароль, подписка, ключ, конфигурация Xray и настройки устройств сохраняются. Установка не активирует перехват трафика.

Панель появляется в LuCI → «Службы» → «Дед Обход». При входе в LuCI по HTTPS браузер не позволяет встроить HTTP-панель: используйте кнопку «Открыть панель» на странице службы. Саму панель следует использовать только в доверенной домашней сети.

Пакет предназначен для OpenWrt 24.10 / RouteRich 24.10 с `opkg`; доступность и совместимость Xray проверяются для конкретной прошивки. Серверную часть Telegram-бота он не устанавливает.
